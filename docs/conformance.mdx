---
title: Conformance
description: Synthetic Burnerform interoperability and failure fixtures.
---

These fixtures keep Burnerform's browser, SDK, and MCP encryption behavior
compatible. Application and agent users do not need to run them.

Independent HTTP clients use these fixtures to verify the
[cryptographic protocol](/docs/cryptographic-protocol) before handling live
forms.

Burnerform contributors can run the repository's `pnpm conformance` test
command to verify valid decryption, canonical form validation, password
wrapping, and rejection of tampered, wrong-form, wrong-key, and wrong-password
inputs. It runs Burnerform's local `scripts/check-conformance.ts` file; it is not
an external package.
