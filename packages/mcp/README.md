# @burnerform/mcp

The local stdio MCP server for autonomous Burnerform creator and respondent
workflows.

Install it from npm with `pnpm add -g @burnerform/mcp`. One local broker safely
serves every Codex task while keeping passwords, private keys, management keys,
and recovery contents outside model context. See
https://burnerform.com/docs/mcp for setup and custody requirements.
